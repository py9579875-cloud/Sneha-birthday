# Sneha's Birthday Website ❤️

A personalized emotional birthday website for Sneha Jaiswal (Hermione).

## Files
- index.html — website structure and birthday message
- style.css — design, responsive layout and animations
- script.js — scrolling, confetti, hearts, photo upload and music controls

## How to run
1. Keep all three files in the same folder.
2. Double-click `index.html` to open it in a browser.
3. For music, place your own audio file in the same folder and name it:
   `birthday-song.mp3`
4. Use the three "Add a memory" boxes to add photos from the device.

## Sharing
You can upload the folder to a static hosting service such as GitHub Pages, Netlify, or Vercel, then send Sneha the website link.

Note: The photo picker currently keeps selected photos in the browser session; it does not upload them to a server.
